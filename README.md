# 🎓 Student Management System

A student management web application built with Laravel + MySQL.

## 🛠 Tech Stack

- PHP 8.2
- Laravel 12
- MySQL
- Blade Template

## ✨ Features

- [ ] Student CRUD
- [ ] Class management
- [ ] Subject management
- [ ] Grade entry by semester
- [ ] Role-based access: Admin / Teacher / Student
- [ ] Grade statistics by class

## ⚙️ Installation

```bash
git clone https://github.com/KaterukuAnh/student-management.git
cd student-management
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

Open your browser at: `http://localhost:8000`
